# 🤖 AI Study Assistant

A beginner-friendly AI learning assistant built for  students.

## 📌 About the Project

AI Study Assistant helps students understand concepts, solve questions, summarize topics, and practice through quizzes, for Programmer use Code Review.

The application provides a simple and user-friendly interface where students can enter their questions and get AI-generated answers.

## ✨ Features

- 📚 Explain concepts in simple language
- 📝 Summarize topics
- ❓ Ask general questions
- 🧠 Generate quizzes
- 💻 Programming help
- ➗ Mathematics questions
- 🌐 Language support
- 🇮🇳 Hindi / Hinglish support
- اردوurdu language support

## 📖 Subjects

The application focuses on three main categories:

### 1. Programming
- C
- C++
- Python

### 2. General Questions
Students can ask general knowledge and educational questions.

### 3. Mathematics
Students can ask mathematical questions and get step-by-step explanations.

## 🛠️ Technology Stack

- **Programming Language:** Python
- **Frontend/UI:** Streamlit
- **AI API:** Groq API
- **AI Model:** GPT-OSS 120B
- **Environment Management:** python-dotenv
